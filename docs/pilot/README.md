# Pilot pack

What a compliance officer receives with an API key:

- [Onboarding guide](onboarding.md): run it, screen a file, call the API, review, keep lists fresh.
- [Data handling](data-handling.md): what is stored, where, who can see it, what is not done yet.
- [Screening methodology](screening-methodology.md): reference data, matching, thresholds, records, in the Wolfsberg vocabulary; attach to the AML manual.
- [Draft outsourcing clause](outsourcing-clause.md): the QCB item 6.7 points a pilot agreement must cover.
- [API reference](../api_reference.md): generated from the OpenAPI schema (`python scripts/export_api_reference.py`).
- [Corridor rules](../corridor_rules.md): what the primary sources say and what the QA-PH ruleset does with it.
- [Monitoring and evidence](../monitoring.md): list versions, re-screening, alerts, review console, evidence bundle.
